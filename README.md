# Nova AI: early prototype and architecture notes

This repository contains an earlier, lightweight Nova prototype and exploratory documentation. It is kept separate from the main application and should not be mistaken for the current deployed codebase.

**Canonical project:** [ange-iracanye/Nova](https://github.com/ange-iracanye/Nova)

The current application is developed in the canonical repository, which contains the React/Vite frontend, FastAPI API, Render configuration, automated tests, and current release checklist.

## What this repository is for

The material here documents early ideas for an AI study tutor, including:

- student-aware tutoring and personalization;
- conversation memory and knowledge retrieval;
- modular tutor-engine architecture;
- local language-model experimentation;
- early roadmap and design notes.

These documents are historical design material, not a guarantee that every described feature exists in the current application.
